# Planning Reference Index

## Folder Routes

| Folder | When To Read | Read Guidance | Commands |
|---|---|---|---|
| `references/plans/active/` | Need project-preserved active plans outside the transient `.planning` workspace. | Read the child index first; current session state still lives in `.planning`. | Inspect active planning files and `git status --short`. |
| `references/plans/completed/` | Need completed plan history that has been promoted out of `.planning`. | Read the child index before using historical plan material. | No default command; verify referenced paths still exist. |

## Update Rule

Use `.planning` for active session memory. Promote only durable project plans here.
