# Table Reference Index

## Folder Routes

| Folder | When To Read | Read Guidance | Commands |
|---|---|---|---|
| `references/dev_references/table/table_schemas/` | Parser, dataframe, validation, or column-contract changes. | Read the schema index and the relevant JSON schema. | Run focused parser/report tests. |
| `references/dev_references/table/table_schema_figure/` | Need visual confirmation of workbook/table columns or report screenshots. | Read the image index and inspect only the needed table image. | No default command; capture schema findings in generated references if updated. |
| `references/dev_references/table/template/` | Workbook template writing, report output, upload sheet, or formatting changes. | Read the template index and the relevant workbook/template notes. | Run workbook-generation tests or a targeted smoke. |
