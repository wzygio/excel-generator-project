【Background】
我要制作一个日报自动生成的项目。本项目分为三个模块：报表下载、数据分析、日报生成。

目前“报表下载”模块已开发完成。请继续帮助我完成“数据分析”模块的开发，并完成相应的任务测试。

【Introduction】
这模块执行流程如下：
1. 理解并分析用户需求：重点在于提取出重要参数，包括但不限于文件名称，产品型号，时间范围，目标数据，分析逻辑等。
2. 文件扫描：目标文件位于resources文件中，扫描包含相应数据表（模糊匹配），并通过表名判断其中是否有符合要求的数据。如果你发现本地没有相应的数据表，则需需要先执行模块一，从报表系统中下载相关数据。
3. 文件解密：读取本地数据表（优先读取解密文件夹“resources\decrypted_files”，在读取resource文件夹），如果发现有文件但文件未解密，则调用文件解密skill“file_decryption”解密文件。
4. 数据分析：读取数据，判定“数据分析方式”，并根据用户需求进行数据分析。比如如果数据量过大，则应先编写代码提取对应数据，再进行分析。最终返回结论。

【Design】
1. 需求解析机制：步骤1和步骤4应使用LLM实现。如何让LLM精准的理解用户需求并执行任务，是本Agent需要设计的核心机制之一。比如您可以设计一些prompt来让LLM精准地提取出关键参数。
2. Agent-Memory机制：
此外，为了确保任务100%执行正确。我们需要建立简单的Agent-Memory和反馈迭代机制。
可能的方式有建立映射表，在每次任务执行成功后（这里的成功是指经用户确认的成功，您可以在UI中添加反馈对话框），将任务记录到映射表中，当有新任务时优先从映射表中匹配。

Example：
a. Step1：需要LLM理解并建立如下映射：“用户需求数据-本地文件名称-报表文件名称”，确保目标数据对应正确的文件和报表名称。
b. Step4：需要LLM理解并建立如下映射：“目标数据-文件中的字段及筛选条件”。“分析逻辑-数据处理方式”。确保目标数据对应数据位置，分析逻辑对应正确的处理方式。
