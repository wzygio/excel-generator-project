2. 个人理解：其实skill架构就是一种较为理想的Agent架构。当前项目的三个模块起始对应的是个三个skill：“报表下载、数据分析、日报生成”。
他们提供接口来让大模型调用。
3. 理想效果：用户可以再输入框中输入需求，Agent根据用户需求完成相应任务。
具体来说：如果我们想要实现一个固定化工作流程，不应该再是写死一套自动执行程序（像我的v1“excel_generator_project”那样），而是接收一份spec文件，其中详细记录了用户需求，而Agent从中拆解出“要下载的报表”、“要分析的数据”、“要生成的日报”。然后依次调用每个模块来完成任务。这才是Agent的标准架构不是吗？
这样当用户想要修改分析流程时，只需要用自然语言修改spec文件即可，而不是让程序员修改代码。
