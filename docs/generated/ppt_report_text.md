# 屏体大数据科-良率监控智能体

> 一页 PPT 汇报文案。版式参考草稿截图：顶部标题 + 项目背景/核心目标；中部左侧“传统模式 VS AI智能体”，右侧“效益核算”；底部“智能体说明”。右下角 UI 展示区可保留为视觉辅助，不作为正文重点。

## 1. 项目背景

当前良率异常管理仍存在人工判断依赖高、异常追踪链路长、信息同步滞后等痛点：异常分析需要跨 Spotfire、FineReport、公盘表格、异常管理表和日报模板反复核对，人工筛查和闭环追踪耗时较高，回复审核标准不统一，日报编写与分发占用固定值班时间。

为提升异常识别准确性、闭环效率和日报时效，项目引入良率监控智能体，推动异常监控、回复审核、闭环追踪、日报生成从人工处理转向标准化、自动化、可追踪的智能协同。

## 2. 核心目标

建立标准化、自动化、可复用的良率异常管理智能体体系，实现数据读取、异常识别、HL 通报、回复审核、闭环追踪、改善确认、日报生成与分发的端到端协同，推动异常分析准确率、审核效率、闭环率和日报及时性同步提升。

## 3. 传统模式 VS AI智能体

| 维度 | 传统模式痛点 | AI智能体方案 | 提升效果 |
| --- | --- | --- | --- |
| 异常识别 | 人工逐条筛查，需跨表核对 Spotfire 数据、异常记录和批次信息，真实异常判断依赖经验 | 自动读取源表，按规则库判断批次产出率、集中性、关键站点超规和历史 HL 状态，识别真实 HL 异常 | 异常筛查效率提升约 80%，减少误判漏判 |
| 异常通报 | HL 文本手工整理，记录和群内推送重复操作多，责任人匹配容易遗漏 | 自动生成 HL 通报文本，同步记录到 HL 记录表和异常管理表，并推送至异常沟通群 | 通报标准化，记录完整性提升 |
| 回复审核 | 异常回复质量依赖人工经验，审核口径不统一，修改示例需要手工整理 | 自动审核回复是否合规，输出改善建议和修改示例，并将有效回复更新至异常管理表 | 审核口径统一，回复质量可持续沉淀 |

| 日报生成 | 值班日报需人工读取源表、判断当日异常、填写模板、刷新下载并分发 | 自动读取过货、良率、目标和异常源表，完成 Gap 判断、异常填报、日报产物生成和分发准备 | 日报编写标准化，释放 70%+ 重复工作 |

## 5. 智能体说明

### 异常监控智能体

标签：异常识别 + 回复审核 + 闭环追踪

- 自动读取 Spotfire 初筛表、CT 良率异常波动管理表、Mapping 图、批次月周天数据等源表。
- 自动判定当日真实异常，识别批次产出率、膜位 / LOT / SHEET / GLASS 集中性、关键站点超规和历史 HL 状态。
- 自动生成 HL 通报，记录至 HL 记录表和异常管理表，并推动责任人响应。
- 自动审核异常回复质量，输出改善建议和修改示例，统一回复审核口径。
- 自动追踪 Open 异常的待更新项和未回复项，推动异常闭环进度。
- 自动确认 Monitor 异常改善效果，辅助异常状态由 Monitor 转 Close。

### 日报生成智能体

标签：源表读取 + Gap 分析 + 日报生成

- 自动读取当日过货数据、良率源表、目标拆解表、异常管理表和日报模板。
- 自动判断当日过货产品，填写异常填报表基础信息。
- 自动识别当日 HL 异常记录，并写入日报当日异常栏。
- 当日良率未达标时，自动分析 Gap 来源，区分新增异常、历史异常、集中过货影响和基础能力不足。
- 自动生成日报 Excel、结构化 JSON 和 Markdown 预览，支撑日报刷新、下载、归档和分发。
