# 日报生成spec

#　Background
针对每个当日过货产品生成一段报告

## 日报样式
1. 目标样式：请参考：“docs\project_files\V3良率日报每日异常填报表代码版本.xlsm”-Sheet1的内容，该页内容即为生成目标。
2. 字段：产品类型-产品-日期-当日异常

## Output

### 报告结构
具体来说，每个产品的报告由以下四部分构成：
1. 当日Gap影响
2. 连续三批次下降原因
3. 已知异常
4. 新增异常

## Workflow

### Step1：提取当日过货产品
从“spotfire数据表”中提取当日过货产品，然后By产品执行后续分析
- 提取逻辑：“产品型号”列对应最终日报中的“产品类型”，“产品”列对应最终日报中的“产品”，“日期”对应最终日报中的“日期”，“当日Gap”对应2.1中是否达标的判定

### Step2：良率Gap分析（对应“当日Gap影响”）
分析当日良率与当月目标良率Gap，判断该产品是否达标。如果不达标，则需继续分析每个Defect Group的Gap，并提取出Top3。然后编写每个Defect Group对应的集中过货影响。具体步骤如下：
1. 从“当日良率表”中提取该产品当日良率
2. 从“良率目标表”中提取该产品当月良率目标
3. 计算Gap：$Gap=当日良率-目标良率$
- 若Gap ＜ 0：不达标，继续执行“良率Gap分析”的后续步骤。
- 若Gap ＞ 0：达标，跳过“良率Gap分析”的后续步骤，分析下一个产品的良率Gap。
4. 从“当日良率表”中提取每个Defect Group的当日良损，从“良率目标表”中提取每个Defect Group的当月目标良损，计算每个Defect Group的良好率Gap
- Defect Group提取逻辑：根据“### Defect Group列表”中列出的Defect Group进行后续匹配。
- 当日良损提取逻辑：“当日良率表”中，依次匹配“Defect Group”（需要注意的是该列的每一行都是一个合并单元格）、“当日日期”（示例：12/11）
- 目标良损提取逻辑：“良率目标表”中，依次匹配“项目代号”（即产品型号）、“Group”（即Defect Group）、“当月月份”（示例：6月）
5. 然后选出Gap值为Top3的Defect Group，分析其“集中过货影响”。
- 集中过货影响判定：“### 集中过货影响判定规则”

### Step3：连续下降分析（对应“连续三批次下降原因”）
连续三个批次（前天良率＞昨日良率＞当日良率）原因（对应1.2）：
1. 请先分析是否出现了连续三天良率下降的情况：
a. 文件名：V3良率及不良率By月周天汇总报表
b. Sheet名：“CT”
c. 文件路径：“resources”，或从报表下载
d. 提取逻辑："Defect Group列，“CT良率”所在行，分析最新三天的变化趋势，是否一直降低。

2. 原因1：受MVI过货占比影响
a. 文件名：V3良率及不良率By月周天汇总报表
b. Sheet名：“CT”
c. 文件路径：“resources”，或从报表下载
d. 提取逻辑："Defect Group列，“CT产出数_MVI产出占比”所在行，分析最新三天的变化趋势，是否一直升高。

### Step4：提取已知已知异常（对应“已知异常”）
判断2.1提取出的Gap Top3的Defect Group中，当日良损最高的Top3 Defect Code。它们近一个月（30天）内是否发生过真实异常。

1. 提取Top3的Defect Group中，当日良损最高的Top3 Defect Code
a. 文件名：V3良率及不良率By月周天汇总报表
b. Sheet名：“CT”
c. 文件路径：“resources”，或从报表下载
d. 提取逻辑：依次匹配“Defect Group”、“Defect Group”右侧一列（即Defect Code）、“最后一列”（即当日良损，示例：6/1）

2. 提取已知异常：“通报日期”为近一个月内
a. 文件名：CT良率异常波动管理表
b. Sheet名：“CT异常波动调查”
c. 文件路径：从“\\10.71.4.18\合肥维信诺公共盘\23专项\大数据专项\02 量产良率\02 良率异常闭环管理”中复制到“resources”下
d. 提取逻辑：依次匹配“产品”（即产品型号）、“不良”（即Defect Code）、“通报日期”（示例：2025/5/10 10:30）、“工艺整合&工艺 回复的改善及挽救进展”（异常回复）
e. 提取字段：【异常原因】、【Inline监控】、【是否止血】、【影响范围】、【改善措施】
f. 回复【异常原因】、【改善措施】两个字段，去掉其中诸如“调查过程”、“申请解析”等冗余内容，只保留与字段最相关的内容

### Step5：新增异常（对应“新增异常”）
1. 提取当日新增异常：“通报日期”为当天
a. 文件名：CT良率异常波动管理表
b. Sheet名：“CT异常波动调查”
c. 文件路径：从“\\10.71.4.18\合肥维信诺公共盘\23专项\大数据专项\02 量产良率\02 良率异常闭环管理”中复制到“resources”下
d. 提取逻辑：依次匹配“产品”（即产品型号）、“不良”（即Defect Code）、“通报日期”（示例：2025/5/10 10:30）
e. 提取异常回复中的以下字段：【异常原因】、【Inline监控】、【是否止血】、【影响范围】、【改善措施】
