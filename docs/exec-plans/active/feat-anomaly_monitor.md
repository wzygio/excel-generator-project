# Anomaly Monitor

## Background
当前项目已经具备了以下三个功能：报表下载、数据分析、日报生成。其中，前两个模块为灵活业务模块，日报生成为固定业务流程。
我们增加一项固定业务流程的功能：真实异常识别。即分析当日异常相关数据，判断出哪些为真实异常。
