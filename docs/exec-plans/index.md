# Plans Index

Use this file to track long-lived project plans and route short-lived execution plans.

## Execution Plan Routing

- Current execution plans: [docs/exec-plans/active/](../exec-plans/active/)
- Completed execution plans: [docs/exec-plans/completed/](../exec-plans/completed/)
- Draft a non-trivial execution plan first, ask the user to confirm it, then write or update the accepted plan under `docs/exec-plans/active/`.
- After implementation, verification, and user acceptance, move the plan to `docs/exec-plans/completed/`.
