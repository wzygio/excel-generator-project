# daily_report

## When To Use
Use this skill when Codex needs to generate the final Excel yield daily report.

## Inputs
- `report_date`: Report date.
- `template_ref`: Optional Excel template path.
- `sections`: Sections to write.
- `analysis_results`: Upstream data-analysis results.
- `output_name`: Optional output file name.

## Outputs
The interface is stable, but the V2 implementation is not connected yet.

## Workflow
This skill currently returns `daily_report.execution.not_implemented`.

## Error Handling
- `daily_report.execution.not_implemented`: V2 implementation is pending.
